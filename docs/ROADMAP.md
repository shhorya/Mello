# Roadmap

1. **Clinical review** of questions, tiers, rules, tips and referral flow (blocker for any real use).
2. **Validated instruments**: official Hindi and regional PHQ-9 / GAD-7 versions.
3. **Real data**: consented, professionally labelled text; per-language evaluation; fairness checks.
4. **Better retrieval and models**: multilingual embeddings; fine-tuned transformer if data allows.
5. **Speech**: Whisper evaluation on Indian-language worker speech; upload endpoint; noise handling.
6. **Delivery**: WhatsApp voice notes and missed-call/IVR with an NGO or CSR partner.
7. **Languages**: Marathi, Tamil, Bengali, Telugu and others, each with rules and knowledge base entries.
8. **Pilot**: small supervised pilot with human counsellors behind escalation; measure retention, referral acceptance and crisis recall.
9. **Partner dashboard**: authentication, consent management, exportable anonymized reports.
